# FS-BOX

> **Lightweight self-hosted file transfer system over TCP/LAN.**

**FS-BOX** — собственная система для передачи и хранения файлов между устройствами в локальной сети.

Проект создаётся с нуля на **Python** с использованием стандартных сетевых механизмов. Основная цель — разобраться в том, как на практике работают TCP-соединения, клиент-серверная архитектура, собственный протокол обмена данными и передача файлов по сети.

## 🏗️ Architecture

На базовом уровне FS-BOX состоит из двух компонентов:

```text
                 TCP
┌─────────────┐       ┌─────────────┐
│   CLIENT    │ ────► │   SERVER    │
│             │ ◄──── │             │
└─────────────┘       └─────────────┘
      │                       │
      │                       │
   User CLI              File Storage
```

**Client** отвечает за взаимодействие с пользователем и отправку запросов.
**Server** принимает подключения, обрабатывает запросы и управляет хранилищем.

В дальнейшем между ними будет реализован собственный прикладной протокол обмена данными.

## 📡 Protocol

FS-BOX постепенно переходит от простого обмена сообщениями к собственному протоколу.


Планируемые команды:

```text
LIST
UPLOAD
DOWNLOAD
DELETE
INFO
EXIT
```

Пример будущего взаимодействия:

```text
CLIENT                     SERVER
   │                          │
   │──── LIST ───────────────►│
   │                          │
   │◄─── file1.txt            │
   │◄─── image.png            │
   │◄─── archive.zip          │
   │                          │
   │──── DOWNLOAD image.png ─►│
   │                          │
   │◄──── file metadata ──────│
   │◄──── binary data ────────│
   │                          │
```

## 🔐 Security

Безопасность является частью дальнейшей архитектуры проекта.


Планируется реализовать:

* authentication;
* authorization;
* user permissions;
* TLS;
* file integrity verification;
* ограничения доступа к файловой системе;
* безопасную обработку клиентских запросов;
* защиту от некорректных данных и протокольных атак.

> **Важно:** текущая версия проекта предназначена для работы в доверенной локальной сети и не должна рассматриваться как production-ready защищённое файловое хранилище.
